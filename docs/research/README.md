# Deep-Research Reports (Agent 1 output)

Drop **AGENT 1** deep-research reports here as `<site>-research.md`, then run
`/new-site`.

Each report should cover: site concept, plan of attack, competitor analysis
(strengths, weaknesses, first impressions, features), how this site beats them,
a feature brainstorm, and the revenue plan (ads + affiliate/partner, plus any
paid tier where profitable).

Agent 1 runs **outside** Claude Code (Gemini Deep Research / GPT Research /
Claude Research); the pipeline only consumes its output. Give an explicit
`APPROVED` before running `/concept`.
